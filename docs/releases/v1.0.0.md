# Opponent-Adjusted Football Metrics v1.0.0

Release date: 2026-06-27

## Summary

v1.0.0 packages the repository as a portfolio-ready football analytics demo. It includes reproducible modelling foundations for CxG, CxA, and baseline CxT, plus a Streamlit dashboard v1 that guides reviewers through player, team, action, and report outputs.

This release is a demo and review surface, not a production deployment.

## Included Features

- CxG feature generation, baseline modelling, validation reporting, generated output checks, model metadata, and API-backed inference.
- CxA feature generation, baseline modelling, attribution, player/team/sequence aggregates, and reports.
- Baseline CxT deterministic zone/grid threat values.
- CxT player/team/sequence aggregates, zone-transition summaries, top-action reports, and interpretation summary.
- Contract-driven Streamlit dashboard v1 with graceful missing-output handling.
- Dashboard storytelling flow, demo walkthrough, dashboard data contract, and v1 release scope docs.
- Generated outputs remain ignored under `feature_store/` and `outputs/`.

## Metrics Available

- CxG: contextual shot quality.
- CxA: baseline chance-creation action value.
- Baseline CxT: threat added by moving the ball between pitch zones.

## Dashboard Features

- Project overview and v1 status banner.
- Player analysis.
- Team analysis.
- CxG, CxA, and CxT pages.
- Action-level explorer.
- Reports and diagnostics page.
- Methodology and guided interpretation text.
- Missing-output guidance for clean checkouts.

## Testing And CI Status

The v1 validation suite covers linting, formatting, non-e2e tests, targeted typing checks, feature/output contracts, API integration, dashboard data loading, and release packaging docs.

Recommended local checks:

```bash
poetry run ruff check src scripts tests app
poetry run black --check src scripts tests app
poetry run pytest -v -m "not e2e"
poetry run mypy src/opponent_adjusted/api/schemas.py src/opponent_adjusted/features/cxg/context.py src/opponent_adjusted/features/cxg/geometry.py src/opponent_adjusted/features/context.py src/opponent_adjusted/features/geometry.py
```

## Reviewer Quickstart

```bash
git clone https://github.com/varunrout/opponent-adjusted-metrics.git
cd opponent-adjusted-metrics
poetry install
poetry run pytest -v -m "not e2e"
make dashboard
```

The dashboard opens even when generated modelling outputs are missing. To populate it with local outputs, run:

```bash
make cxg-smoke
make cxa-smoke
make cxt-baseline
```

## Known Limitations

- The dashboard is a demo/portfolio dashboard, not a production deployment.
- Generated outputs are not committed and must be regenerated locally.
- Baseline models are intended for reproducible review, not production-grade calibration claims.
- StatsBomb Open Data and event-data-compatible features are the expected data foundation.
- Tracking data is not required or included.

## Deferred Enhancements

- CxT+ is not implemented in v1.
- Contextual CxT is not implemented in v1.
- Advanced CxT is not implemented in v1.
- OD-CxT and OD-CxT+ are not implemented in v1.
- Live data ingestion, production deployment, monitoring, and model registry workflows are deferred.
